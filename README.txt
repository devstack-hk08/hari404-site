HARI404 — 3D SCROLL PORTFOLIO

Quick start:
1. Extract this folder.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. Upload the whole folder to GitHub Pages, Netlify, or Azure Static Web Apps.

Files:
- index.html       Main portfolio
- styles.css       Responsive visual design, 3D effects and animations
- script.js        Scroll progress, reveal animations, cursor glow, portrait tilt
- assets/          Your supplied portrait

Customize:
- Update the email address in index.html (currently hello@hari404.dev).
- Replace project URLs if needed.
- Edit copy and skills directly in index.html.

The site uses Google Fonts from the web. All other assets and code are local.
